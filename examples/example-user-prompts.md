# Example User Prompts

## Install workflow into a source zip

```text
Add the light delivery workflow to this source-code zip.
```

## Install workflow using an uploaded plan

```text
Add the light delivery workflow to this source-code zip and use the uploaded plan as docs/delivery-plan.md.
```

## Execute one step

```text
Follow AGENTS.md and implement the next incomplete step.
```

## Execute one step with explicit zip behavior

```text
Use the uploaded zip as the source of truth. Follow AGENTS.md and implement the next incomplete step only. Update progress and return an updated zip.
```

## Repair workflow files

```text
Repair the delivery workflow files in this zip without modifying application source code.
```

## Convert an existing plan

```text
Convert the existing plan in docs/ into docs/delivery-plan.md and initialize docs/agent-progress.md.
```
